# Atlas 3D Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A pt-BR web page showing a 3D human body with filterable layers and a details panel for the clicked structure.

**Architecture:** An offline pipeline turns the Z-Anatomy `.blend` into one compressed GLB per layer plus `structures.json`. Blender only exports geometry and original names; all naming and exclusion logic is TypeScript, so it can be tested. A static Three.js page consumes those files.

**Tech Stack:** TypeScript, Vite, Three.js, Vitest, Blender (headless, Homebrew), @gltf-transform/cli (meshopt). No UI framework.

**Spec:** `docs/superpowers/specs/2026-11-25-atlas-3d-design.md`

## Global Constraints

- All user-visible text is pt-BR.
- Source: official `Z-Anatomy/Models-of-human-anatomy`; record the commit in `tools/convert/SOURCE.md`.
- Inner ear and kidneys are excluded from every output.
- Unreviewed descriptions show "não revisado". Missing ones show "Descrição em preparação". No Wikipedia text.
- Converted models and adapted data are CC BY-SA 4.0 (`LICENSE-ASSETS`). Add no licence for app code.
- The page states it is educational and not medical advice.
- Source downloads go in `.cache/` (gitignored). No public deployment.
- Commit messages carry no AI attribution.

## Review Focus

- A structure with no translation: shows its English name flagged "sem tradução", never blank or `undefined` (Task 2).
- Search typed without accents ("femur", "musculo"): finds "Fêmur", "Músculo" (Task 4).
- Clicking through a hidden or isolated-away structure: only visible meshes can be picked (Task 4).
- A layer toggled off while still loading: stays off when loading ends, and loads only once (Task 4).
- A layer file that fails to load: pt-BR error with retry; other layers keep working (Task 4).

### Task 2: Names, exclusions and metadata

**Files:** Create `package.json`, `tsconfig.json`, `src/types.ts`, `tools/convert/names.ts`, `tools/convert/build-data.ts`, `tests/names.test.ts`

**Interfaces:**
- Consumes: Task 1 inventory and translation file (`;`-separated, header `English;Latin;Français;Español;Portugues`).
- Produces:
  - `type LayerId = 'esqueleto'|'articulacoes'|'musculos'|'cardiovascular'|'nervoso'|'orgaos'|'linfatico'`
  - `interface Structure { id: string; sourceName: string; layer: LayerId; namePt: string; nameLatin: string|null; side: 'esquerdo'|'direito'|null; translated: boolean }`
  - `parseName(raw: string): { base: string; side: Structure['side'] }`
  - `parseTranslations(csv: string): Map<string, {latin: string; pt: string}>` (keys lowercased)
  - `isExcluded(name: string, collections: string[]): boolean`
  - `toStructure(item, layer, translations): Structure`
  - `build-data.ts` writes `public/data/structures.json` (`Structure[]`) and `.cache/export-list.json` (`{id, sourceName, layer}[]`).

- [ ] **Step 1:** Write failing tests. Adjust fixture names to the conventions in the real inventory.

```ts
expect(parseName('Femur.l')).toEqual({ base: 'Femur', side: 'esquerdo' })
expect(parseName('Femur.r.001')).toEqual({ base: 'Femur', side: 'direito' })
expect(parseTranslations('English;Latin;Français;Español;Portugues\nFemur;Femur;Fémur;Fémur;Fêmur').get('femur')).toEqual({ latin: 'Femur', pt: 'Fêmur' })
expect(isExcluded('Left kidney', [])).toBe(true)
expect(isExcluded('Cochlea.l', [])).toBe(true)
expect(isExcluded('Femur.l', ['Skeletal system'])).toBe(false)
expect(toStructure({ name: 'Unknown part' }, 'orgaos', new Map())).toMatchObject({ namePt: 'Unknown part', nameLatin: null, translated: false })
```

- [ ] **Step 2:** `npx vitest run`. Expected: FAIL.
- [ ] **Step 3:** Implement. Build the exclusion terms from Task 1's list; match by collection as well as name, and don't exclude unrelated structures (for example "adrenal"/"suprarenal" glands and the vestibule of the mouth). Add tests for those two.
- [ ] **Step 4:** Tests pass. Run `build-data.ts`; it prints counts per layer, excluded names and untranslated count. Review the excluded list, and list names that look European Portuguese for the final report.
- [ ] **Step 5:** Commit: `feat: build structure metadata in Portuguese`
